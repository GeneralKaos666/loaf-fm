Follow-up patch to **v0.2.0** focused entirely on fixing installation and packaging. Previously, packages and install methods were hit-or-miss across distros because builds were compiled on a single NixOS machine, causing compatibility headaches and `/nix/store` path errors elsewhere.

## What's Fixed

### 🔄 Automated CI/CD Builds
All packaging now runs on standard GitHub Actions Ubuntu workers instead of a local NixOS machine. This eliminates environment-specific glibc, Qt, and `/nix/store` path errors across distros. New releases are automatically built and published when a version tag is pushed.

### 📦 Rebuilt Release Packages
Every artifact on this release is compiled fresh against standard Ubuntu 24.04 libraries:
- **Debian / Ubuntu**: `.deb` with Qt6 dependencies correctly declared
- **Fedora / RHEL**: `.rpm` installed to `/usr` (no more `/nix/store`)
- **Arch**: `.pkg.tar.zst`
- **Universal**: portable `.tar.gz` and standalone `.AppImage`
- **SHA256SUMS** checksums for verification

### 🔧 Overhauled Installer
The `curl | bash` installer was rewritten:
- Removed the interactive `gum` dependency that could hang on piped or non-TTY installs
- Visible download progress instead of silent background fetches
- New flags: `--appimage`, `--tarball`, `--update`, `--uninstall`, `--try`
- Clean NixOS detection with helpful instructions instead of broken installs

### 📜 Legal / Compliance (#61)
- Added MIT LICENSE
- Added THIRD-PARTY-LICENSES.md
- Proper license metadata in all packaging files

### 📥 Arch User Repository
Loaf is now available on the AUR as `loaf-fm`:
```bash
yay -S loaf-fm
```

## Included Changes
- Show non-file GTK bookmarks in sidebar (#44)
- Rename `native` context property to build with Qt 6.8 (#56)
- Add new tab and window toolbar buttons (#59)
- Full packaging, CI, and installer overhaul

## Looking Ahead — v0.3.0
Work is underway to expand distribution significantly: Flathub, native APT and DNF repositories, upstream nixpkgs support, and automated nightly releases.
